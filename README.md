# 신호 복구실

고등학교 정보 수업에서 사용하는 8단계 알고리즘 퍼즐입니다. 세 칸의 빛 신호를 명령 카드로 처리하고 실행 과정을 추적합니다.

## 수업 흐름

도입 5분, 퍼즐 36분, 정리 5분, 이동·질문 4분을 권장합니다. 단계별 시간은 3·3·4·4·5·5·5·7분입니다.

1. 신호의 방향 — 순차 실행
2. 끊임없는 도착 — 반복
3. 손상 신호 격리 — 조건 선택
4. 암전 방지 회로 — 조건의 위치
5. 도시 충전기 — 상태와 누적
6. 복원 모듈 만들기 — 함수와 추상화
7. 통과한 코드의 함정 — 반례와 디버깅
8. 마지막 전송 — 통합과 종료

페이지의 ‘수업 안내’에 예시 구조와 정리 질문이 있습니다. 모든 단계에 바로 들어갈 수 있습니다. 실행·일시정지·한 단계·이전 단계·다시 실행을 지원하며 전체 검사는 모든 고정 검증 사례를 확인합니다.

## 로컬 실행

학생이 사이트를 사용할 때는 패키지 설치가 필요하지 않습니다. 개발·테스트에는 Node.js 20 이상과 Python 3을 사용합니다. jsdom은 테스트 전용 개발 의존성입니다.

```sh
npm ci
npm test
npm start
```

브라우저에서 http://localhost:4173 을 엽니다. ES modules를 사용하므로 파일을 직접 더블클릭하는 대신 HTTP 서버로 실행합니다.

## 개인정보와 저장

학생 이름·학번·이메일·계정을 받지 않습니다. 작성한 카드, 완료 단계, 힌트, 반례 확인과 동작 줄이기 설정만 브라우저의 localStorage에 저장합니다. 답안을 서버로 전송하지 않으며 외부 분석 도구나 외부 글꼴이 없습니다. 기기가 바뀌면 진행이 자동으로 이전되지 않습니다. 저장이 차단된 경우에도 현재 페이지에서 풀이를 계속할 수 있습니다. GitHub Pages 호스팅의 일반 접속 기록은 GitHub 정책을 따릅니다.

## 구조

- `src/engine.js`: 제한된 명령 실행과 불변 실행 기록
- `src/levels.js`: 8개 단계의 카드 설정·입력·목표·검증
- `src/storage.js`: 버전이 있는 로컬 저장과 오류 복구
- `src/app.js`, `styles.css`, `index.html`: 한국어 반응형 인터페이스
- `tests/`: 실행·검증·저장·UI 계약 테스트

자유 코드를 평가하지 않습니다. 입력이 너무 오래 처리되면 200단계에서 안전하게 멈춥니다. 기본 복원은 왼쪽 회전 후 첫 칸 반전이고, 4단계부터는 결과가 000일 때 마지막 칸을 켭니다. 종료 표지는 8단계에서 처음 등장합니다.

## GitHub Pages

저장소의 `main` 브랜치 루트를 Pages 게시 원본으로 사용합니다. 모든 자산은 상대 경로이며 단계 주소는 `#stage-1`부터 `#stage-8`까지입니다. 별도 빌드나 서버가 필요하지 않습니다.
